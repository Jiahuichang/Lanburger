# Lanburger — Instructions for AI coding agents (Codex and others)

This project keeps ONE set of instructions: **read `CLAUDE.md` and follow it exactly.** It applies to every agent,
not only Claude. Do not copy its rules here; copies go out of date.

Before any change, also read `PROJECT_STATUS.md` and `docs/IMPLEMENTATION_PLAN.md`.

Workflow (GitHub `main` is the source of truth):

1. At the start: `git pull` on `main`.
2. At the end: commit and push to `main`, never force-push, and update `PROJECT_STATUS.md` so the next computer
   knows where work stopped.
