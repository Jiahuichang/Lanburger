## 朋友照片的存放規則（隱私）

- 請放在 `references/private/`。這個路徑已經加進 `.gitignore`，**不會被推上 GitHub**。
- 進 repo 的只有轉換後的像素角色（sprite、頭像）和文字版的「角色設定卡」（髮型、配色、配件），不放原始照片。
- 每位朋友一個子資料夾，例如 `references/private/npc-mia/`，可以附一行備註寫希望的角色定位。
