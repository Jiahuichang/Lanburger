## R4 做了什麼

- **Greetings 課程，共 3 課 9 句**：打招呼與道別、自我介紹、問候近況。
  - 5 種學習語言都有：英、西、德、日、繁中。
  - 說明可以選英文或繁中（Settings 的「Lesson explanations in」），每種語言還有專屬的小提示。
- **上課流程**：
  1. Maggie 用對話帶出情境。
  2. 簡短說明。
  3. 範例卡：大字、讀音、意思，可以按 Listen 聽發音。
  4. 練習題，共 3 種題型：看句子選意思、看意思選說法、別人說一句話時選合適的回答。
  5. 每題立刻回饋：答錯會說明原因並可以重試；錯兩次會直接告訴你答案，選了答案才繼續，不會卡住。
  6. 結算畫面列出學會的句子，最後 Maggie 說一句結語。
- **間隔複習（Leitner）**：每個句子會記住你的熟練度，到期的句子會出現在右上角 **Learn** 按鈕的複習裡。複習不扣體力。
- **體力**：
  - 上課時答錯扣 1 點，最低到 0。
  - 體力 0 時照樣能上課，會提示目前是練習模式。
  - 教室左邊書櫃的 **Practice Corner** 可以免費練習，完成一輪回復 5 點體力，不用等待也不用付費。
- **發音**：Listen 用瀏覽器內建的語音，大部分手機和電腦都有，沒有的裝置會自動隱藏按鈕。

## 待辦和限制

- **母語者校對**：5 種語言的內容都標記為「尚未校對」（`reviewed: false`），正式推出前要請母語者看過。
- **XP、升級、燈籠、配料**：還沒和課程連動，這些是 R5（任務與成長）的範圍。
- **語音**：發音的品質取決於裝置內建的語音。
