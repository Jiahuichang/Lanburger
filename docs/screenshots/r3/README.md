## R3 做了什麼

- **對話系統**：
  - 對話是資料檔（`src/content/dialogues/`），可以有分支選項，選了會設定劇情旗標並存檔。
  - 對話框有頭像（6 種表情）、名字、逐字顯示的文字（按一下直接顯示整句），以及選項。
  - 鍵盤、滑鼠、觸控都能操作。開啟減少動態時，文字直接整句顯示。
- **9 位 NPC 都有自己的對話**：Mayor Bun 和 Maggie 有主線開場；其他人是有個性的閒聊，各有 2 個選項。
  - 跟 Mayor Bun 或 Maggie 說過話之後，她們頭上的 `!` 會變成 `…`，下次說的話也會不同。
- **NPC 會動**：
  - 在家附近慢慢散步。玩家靠近時停下來轉頭看你，說話時會播說話動畫。
  - 店長和 Remy、Ash 會待在原地。
  - Mochi 會跟著 Noah 走。
  - NPC 和玩家之間有碰撞，不會互相穿過。
- **建築進出**：
  - 走到 Language Academy 門口往上走（或按 Enter），淡出後進入教室；往下走出門就回到門口。
  - 室內用溫暖的室內燈光，不套黃昏色調。
  - 存檔會記得你在室內還是室外。
- **Language Academy 教室**：Maggie 在裡面，下一階段（R4）的 Greetings 課程會在這裡上。

## 已知限制

- 目前只有 Academy 可以進去。其他建築按 Enter 只會顯示介紹，室內會隨各自的主題一起做。
- NPC 散步只是在家附近隨機走，不會沿路線走或去別的地方。
